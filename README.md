# Rockide for Visual Studio Code

VSCode extension for Minecraft Bedrock that provides rich auto-completions, go-to definitions, and schema validation.

## Features

Supported language features for JSON files:

- Completions
- Go to definitions
- Symbol rename
- Schema validation
- Embedded mcfunction & molang

Supported language features for Molang:

- Completions
- Go to definitions
- Hover
- Signature help
- Syntax highlighting

Supported language features for mcfunction:

- Completions
- Go to definitions
- Hover
- Signature help
- Syntax highlighting

## Planned Features

These features are not yet implemented but are planned to be added:

- Project diagnostics
